# Blog Web Application

A simple web application built with Node.js, Express.js, EJS and Css.

## Features
- Create new blog posts
- View existing posts
- Edit posts
- Delete posts
- Responsive layout

## Technologies Used
- Node.js
- Express.js
- EJS
- HTML
- CSS
- Git and GitHub

## What I Learned
This project helped me practice server-side routing, form handling, dynamic page rendering with EJS, and organizing a Node.js web application.

## How to Run

1. Clone the repository
2. Run npm install
3. Run node app.js
4. Open the local server in your browser.
